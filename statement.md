## Project Statement 
Managing books manually in a library can be time-consuming and difficult. It is necessary to maintain book details, track availability, and manage borrowing and returning efficiently.
The Library Management System in Java is developed to simplify these tasks by providing features to add, remove, display, borrow, and return books through a simple menu-driven interface.

## Scope of the Project
- Manage book details efficiently.
- Add and remove books from the library.
- Track book availability.
- Manage borrowing and returning of books.
- Provide a simple and user-friendly interface.
- Can be extended with database, login system, fine calculation, and GUI in the future.

## Target Users
- Students – To borrow and return books.
- Librarians – To manage books and their availability.
- Library Staff – To maintain and update library records.

## High Level Features
- User Account Creation
- Book Management – Add, view, and remove books
- Book Borrowing & Returning
- Book Availability Tracking
- Automatic Book ID Generation
- Menu-Driven Interface
- Basic Error Handling
